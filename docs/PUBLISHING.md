# 后续发布到 GitHub

当前阶段只准备本地源码和扩展 ZIP，没有创建远程仓库或公开发布。

- `main`：用于未来公开的独立源码快照，包含 MIT 许可证、上游来源、安装说明和测试构建 CI。
- `work/edgeever-clipper`：本地开发与审阅历史。不要使用 `git push --all`；开发基线历史曾包含上游许可排除的品牌/商店资源，当前发布快照已移除这些文件。
- `builds/*-source.zip`：不包含 `.git`、依赖、构建输出或本地浏览器设置的源码包。
- `builds/*-chrome.zip`：加载到 Chromium 浏览器的扩展包。

正式发布前，应完成真实 Edge/Chrome 安装和 EdgeEver 实例验收，填写仓库名称及维护者/安全报告联系方式，再创建远程仓库并只推送 `main`。确认依赖许可证和浏览器扩展隐私说明后再制作公开 Release；当前 CI 不会自动上传任何产物。
